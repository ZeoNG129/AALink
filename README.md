# AALink — AE 无线自动连接

一个 Minecraft 1.20.1 Forge 模组，让 AE2 设备**无视距离、无视维度**自动接入你的 ME 网络。

## 功能

放置**无线连接器**（Wireless Connector）进 AE 网络后，在任意位置放置任何能连接 AE 网络的方块（ME 线缆、输入/输出总线、存储总线、机器等），它们会自动接入该网络——无需拉线、无需存储总线。

- **无视距离**：设备放多远都能连上
- **无视维度**：跨维度也能连
- **重启持久化**：服务器重启后自动恢复连接，无需重新放置

## 使用

1. 把 **无线连接器** 放进你的 AE 网络（旁边有 ME 线缆/控制器即可）
2. 在任意位置放置要接入的设备
3. 设备自动并入网络，立即可用

## 前置

- Minecraft 1.20.1
- Forge 47.x
- Applied Energistics 2（AE2）

## 构建

```bash
./gradlew build
```

产物在 `build/libs/`。

## 合成配方

无线连接器由 4 个赛特斯石英 + 4 个红石 + 1 个末影珍珠合成。
